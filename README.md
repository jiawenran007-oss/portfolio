# Wren Jia — Portfolio

Personal portfolio by Wren Jia. Environmental design, character design, painting and printmaking.

## Website

Static website: `index.html` and `assets/`. No installation or build step is required.

Features: water reveal and returning mist, three color themes, gouache painting, folding project index, pointer-controlled gallery, interactive project sphere, and scroll typography.

All artwork belongs to Wren Jia.

## Local preview

Run `python -m http.server 8000` from this directory, then open http://localhost:8000.

## Hosting

GitHub Pages: deploy from the `main` branch and `/ (root)` folder.
